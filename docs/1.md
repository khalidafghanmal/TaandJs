## 7. npm / create flow

| Path | Purpose |
|------|---------|
| `bin/create.js` | Core scaffolder — copies project to a new directory |
| `packages/create-taand/` | Publishable `create-taand` npm package |
| `package.json` → `"create": "node bin/create.js"` | Local create script |
| `package.json` → `bin.create-taand` | Bin alias for local use |

### Create a new app locally

```bash
cd TaandJs
node bin/create.js ../my-new-app
# or
npm run create -- ../my-new-app
```

### After publishing to npm

```bash
npm create taand@latest my-app
cd my-app
npm run dev
```

Options:
- `--no-install` — skip `npm install` and migrations

## Before you push — final checklist

- [ ] Update `repository` URL in `package.json` to your real GitHub repo
- [ ] Confirm `.env` is **not** committed (`git status`)
- [ ] Confirm `node_modules/` and `vendor/` are **not** committed
- [ ] Run `npm test` and `npm run build` locally
- [ ] Create GitHub repo and `git push`
- [ ] (Optional) Publish `create-taand` to npm from `packages/create-taand/`
